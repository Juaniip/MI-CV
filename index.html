03.

Proyectos

Sistemas operativos · Founder & Lead

LINSI-OS

Distribución GNU/Linux construida desde código fuente con la metodología Linux From Scratch, para docencia, investigación y desarrollo en el Laboratorio LINSI. Cada componente se descarga, se verifica contra su checksum oficial y se compila para un target propio (x86_64-linsi-linux-gnu).

  • Kernel endurecido: Lockdown, KASLR, Secure Boot y BTRFS.
  • Seguridad: LUKS2 + Argon2id, SELinux, nftables, auditd, PAM con FIDO2 y DNS-over-TLS.
  • Paquetes con apk-tools y repositorio firmado; escritorio Wayland + KDE Plasma 6.
  • Builds en contenedores (Podman / Docker), un script por fase. Equipo de 3.
  • Bash
  • Linux From Scratch
  • GCC / Clang
  • systemd
  • SELinux
  • Podman

Automatización · Self-hosting

AutoPublisher

Panel web para preparar, programar y publicar videos y Shorts en varios canales de YouTube: guiones con Gemini, calendario de publicación, subida por la API de YouTube y backup automático en Google Drive.

  • Cola de subidas con reintentos y manejo de la cuota diaria de la API.
  • Seguridad en dos capas: Cloudflare Access + login propio (scrypt, CSRF, CSP/HSTS).
  • Corre en una Raspberry Pi con Docker (sin root, solo lectura) detrás de un Cloudflare Tunnel.
  • Node.js
  • SQLite
  • YouTube Data API
  • Gemini API
  • Docker

Sitio para potenciales inversores de la primera red de cerveza inteligente, donde el usuario arma visualmente su modelo de franquicia (Food Truck, Parador o Clásico).
